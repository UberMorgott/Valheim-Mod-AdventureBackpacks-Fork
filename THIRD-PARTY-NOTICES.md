## Adventure Backpacks 2.4.6 models and translations

## No other third-party source

- The plugin contains no source code from other projects. Logging, config binding and sync, recipe and drop
  configuration, per-item backpack data, bone rebinding and the shader swap are this fork's own code, built on
  BepInEx, Jotunn (<https://github.com/Valheim-Modding/Jotunn>, MIT, referenced as a NuGet package, not
  bundled) and the vanilla game API.
